# Nick the Shape Man

A shape-shifting platformer. Restore color to a world gone gray.

Built with Godot 4 (GDScript).

## Controls

| Input | Action |
|-------|--------|
| A / D | Move left / right |
| W | Jump (coyote jump, double jump, wall jump) |
| Shift | Run |

## Requirements

- [Godot 4.x](https://godotengine.org/) with .NET / C# support

## Running

Open `project.godot` in Godot 4 and press F5.
